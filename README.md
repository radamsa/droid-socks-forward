# Socks Forward

SOCKS5-прокси, который работает на самом телефоне. Приложение слушает входящие
соединения, само открывает исходящие TCP-соединения и отдаёт их в сеть. Если на
устройстве включён системный VPN, трафик автоматически уходит через него.

- **minSdk 21** (Android 5.0), targetSdk 36; рассчитано на слабые устройства и Android Go.
- В основном окне — статистика трафика и список активных соединений.
- В настройках — адрес прослушивания, порт, необязательная авторизация, лимиты.
- Поддерживается только `CONNECT` (TCP). `BIND` и `UDP ASSOCIATE` не реализованы.

## Сборка

Нужны JDK 17 и Android SDK (platform 36).

```bash
./gradlew assembleDebug      # app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease    # минифицированный APK
./gradlew test               # юнит-тесты протокола и сервера (:core)
```

Те же шаги и подготовка APK через Make:

```bash
make setup   # проверка Android SDK, local.properties, подготовка wrapper
make build   # debug APK + тесты core
make release # release APK + тесты, готовый файл в dist/socks-forward-<версия>.apk
make clean   # очистка результатов сборки
```

Release-сборка подписывается debug-ключом, если рядом нет `keystore.properties`:

```properties
storeFile=release.jks
storePassword=...
keyAlias=...
keyPassword=...
```

APK ставится вручную (`adb install -r app-debug.apk`) или любым файловым
менеджером. Google Play не используется, поэтому ограничения политики
`specialUse` foreground service не применяются.

## Использование

1. Откройте настройки, отметьте адреса и порт (по умолчанию `127.0.0.1:1080`).
   Адреса берутся из интерфейсов телефона, можно выбрать несколько — например
   loopback плюс Wi-Fi; либо «Все интерфейсы (0.0.0.0)».
2. Нажмите «Запустить» — появится постоянное уведомление, сервис работает в фоне.
3. Подключите клиент:
   - на этом же телефоне: `socks5://127.0.0.1:1080`;
   - с другого устройства: отметьте адрес Wi-Fi или «Все интерфейсы (0.0.0.0)»,
     адреса показаны на главном экране (например `192.168.1.42:1080`).

Кнопка «Остановить» (в приложении или в уведомлении) закрывает сокеты и все
активные соединения.

## Про VPN

Трафик выходит обычными сокетами процесса, поэтому системный VPN (VpnService)
перехватывает его так же, как трафик любого другого приложения. Работает это при
двух условиях:

- приложение **не исключено** из VPN в настройках раздельного туннелирования;
- VPN не является «прокси в настройках Wi-Fi» — такой прокси влияет только на
  HTTP-клиенты и на raw-сокеты не действует.

Проверка: сравните внешний IP с включённым и выключенным VPN, а также счётчик
трафика в VPN-клиенте.

## Безопасность

- По умолчанию прокси слушает только `127.0.0.1` — снаружи недоступен.
- При выборе `0.0.0.0` главный экран показывает предупреждение, если авторизация
  выключена. Включайте логин/пароль, если сеть не вызывает доверия.
- Пароль хранится в обычных `SharedPreferences` (без шифрования). Это локальный
  прокси-пароль, но не используйте здесь значимые пароли.
- Порты ниже 1024 недоступны без root.

## Устройство проекта

```
core/   чистый JVM-модуль: протокол SOCKS5, движок, модели (тестируется без Android)
app/    UI на Views, foreground service, настройки
```

- `core/.../socks/Socks5Handshake.kt` — разбор и сборка протокола.
- `core/.../Socks5ProxyServer.kt` — accept-loop, пул соединений, перекачка байт,
  half-close, счётчики.
- `app/.../service/ProxyService.kt` — foreground service типа `specialUse`.
- `app/.../proxy/ProxyManager.kt` — единый `StateFlow` для UI и сервиса.

Потоки: на каждое соединение два блокирующих чтения на выделенном cached pool,
число потоков ограничено настройкой «Максимум соединений» (по умолчанию 32).

## Тестирование

```bash
./gradlew :core:test
```

Покрыто: greeting, авторизация (RFC 1929), IPv4/домен/IPv6, неизвестные команды
и типы адресов, обрезанные пакеты, сквозной CONNECT через локальный echo-сервер,
отказ в соединении.

Быстрая проверка на устройстве без Wi-Fi:

```bash
adb forward tcp:1080 tcp:1080
curl --socks5-hostname 127.0.0.1:1080 https://example.com
```

## Ограничения

- Только TCP `CONNECT`: UDP/QUIC пойдут напрямую (браузер откатится на TCP),
  `BIND` не поддерживается.
- Автозапуск при загрузке не реализован.
- Статистика живёт в памяти и обнуляется при перезапуске прокси.
- На некоторых прошивках (Xiaomi, Huawei) система агрессивно убивает фоновые
  сервисы — разрешите приложению работу в фоне.
